# Security policy

## Supported versions

Security fixes are applied to the latest released version of MacPins.

## Reporting a vulnerability

Please avoid posting exploit details in a public issue. Use GitHub's private
vulnerability reporting for this repository. If that option is unavailable,
open a minimal issue asking the maintainer to contact you privately.

MacPins uses Screen Recording and Accessibility solely for local window
capture, parking, restoration, and focus. It does not upload captures or
collect analytics.
